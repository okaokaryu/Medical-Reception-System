# 医療機関向けオンライン受付システム

## 概要

本リポジトリは、本学のソフトウェア工学の授業で7人チームにより開発した「医療機関向けオンライン受付システム」に関する成果物です。

患者と医療機関双方の受付業務を効率化することを目的とし、診療予約から受付、患者管理までを一貫して支援するシステムを開発しました。

※本リポジトリには、私が担当した成果物および公開可能な資料のみを掲載しています。

# システム概要

## 患者向け機能

- 会員登録
- ログイン
- 診療予約
- 問診票入力
- QRコード受付
- 診療履歴確認
- 処方箋履歴確認

## 医療機関向け機能

- 待機患者管理
- 患者カルテ確認
- 部屋案内
- 受付管理
